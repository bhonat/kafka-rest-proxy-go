# Notices

This project depends on third-party open-source libraries. Generate and review
dependency notices before any public release.

The repository currently includes an Apache-2.0 root `LICENSE`. Confirm that
license choice with the project owner before publishing or redistributing
artifacts.

Minimum release checklist:

- [x] Add root `LICENSE`.
- [ ] Generate dependency notice/SBOM artifacts.
- [ ] Review dependency licenses.
- [ ] Confirm Docker base image notices.
- [ ] Confirm whether generated benchmark reports may be redistributed.
